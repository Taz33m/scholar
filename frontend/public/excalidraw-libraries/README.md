Bundled Excalidraw library files in this folder come from the public
[`excalidraw/excalidraw-libraries`](https://github.com/excalidraw/excalidraw-libraries)
repository.

Included sources:

- `charts.excalidrawlib`
- `graphs.excalidrawlib`
- `mathematical-symbols.excalidrawlib`
- `math-teacher-library.excalidrawlib`
- `montessori-basic-grammar-symbols.excalidrawlib`
- `organic-chemistry-basics.excalidrawlib`
- `software-architecture.excalidrawlib`

These files are loaded locally by the tutor canvas so the product does not
depend on GitHub availability at runtime.
